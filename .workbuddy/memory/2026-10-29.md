# 2026-10-29

## 系统管理新增「进程管理」（v1.5）
- 新增 `internal/system/process.go`：两轮 `Times()` 采样算瞬时 CPU、全量进程详细字段、多字段排序、按名过滤、`KillProcess`（SIGTERM/SIGKILL，拒 PID≤1 与自身）
- 新增 `internal/system/proc_threads_windows.go` / `proc_threads_unix.go`：Windows 用一次 toolhelp 线程快照批量算线程数，解决 `NumThreads()` 每进程 13ms 的性能瓶颈
- 新增 `internal/api/process.go`：`GET /api/system/processes`、`POST /api/system/processes/kill`，注册在主机组与 Agent 路由
- 新增 `web/src/views/Processes.vue`，路由 `/system/processes`，系统管理菜单加子项
- 排查过程记录：初版 CPU 出现 1869% 的异常值，定位为「固定 300ms 采样窗口 + Windows 全量遍历耗时 8.3s」双重问题；改为每进程实测 Δt + 批量线程数后，耗时降到 0.5s、数值恢复正常
- 新增 `internal/system/process_test.go`：排序、过滤、自身字段、Kill 防护
- README 功能表 / 目录结构 / 安全说明同步更新
